# Nexorian AI Writing Assistant

Sovereign writing tools for ads, product descriptions, emails, whitepapers, and more.

**No external API keys.** Uses your Nexorian / Jarvis local inference.

## Setup
1. `npm install`
2. Point `NEXORIAN_INFERENCE_URL` at your local Jarvis/Ollama endpoint
3. `npm run dev`

Part of the Nexorian / VITA sovereign stack.
